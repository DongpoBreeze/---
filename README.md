# 日常有节

“有节”是一款本地优先的日常健康记录 App：拍照或手填饮食、记录整次力量训练与睡眠，在本机算出营养、BMI 与趋势，需要时再交给自己配置的 AI 做识别和总结。记录默认只保存在设备上，可完整导出恢复。

[![有节宣传动画预览：饮食、训练、睡眠、今天、趋势、本地备份与 AI 设置](docs/media/youjie-promo.webp)](docs/media/youjie-promo.mp4?raw=true)

上图为 82 秒宣传动画的无声预览；点击图片可下载带配乐的 1080p 完整版（MP4，约 24 MB）。

底部四个 Tab：**今天**（当日状态与记录入口）、**趋势**（7 / 30 日）、**我的**（目标、身体资料和“全部记录”子页面）、**设置**（外观、AI 服务与数据管理）。

技术栈为 Expo、React Native 和 TypeScript，Android / iOS 共用客户端，Web 用于开发预览。

## 使用

- 在“设置 → AI 服务设置”填写自己的 HTTPS URL 和 Key，选择 Responses 或 Chat Completions 协议，获取模型并选择模型及推理强度；支持服务默认、上游选项和自定义强度。App 直接连接所选服务，开发网关只用于诊断。默认预填 `https://api.bblabu.ai/v1`，没有内置 Key、模型或选定强度。
- 原生配置使用 SecureStore，Web 使用独立 IndexedDB，写入提交后才提示保存成功；同一浏览器、同一来源重开后恢复。健康 ZIP 不包含 AI 连接配置或 Key。旧版仅存于内存且已丢失的配置需重新填写一次。
- 饮食可手动记录，也可追加或一次多选餐前照片，同餐最多 4 张；旧餐后照片继续兼容。识别后在独立页面核对菜品、每 100 g 营养与食用量，确认后同步餐名和四项营养。本地默认量可修改或清空，属于一般成人参考估计，不能视为照片称重；旧餐保存量不随新资料重算。
- 力量训练以整次训练为单位，可包含多个动作；选择模板（如“拉日”）一次带出全部动作，或从空白训练逐个添加。每个动作默认只填组数 × 次数 × 重量，需要时展开逐组调整。“存为模板”保存训练名称、动作顺序、组数和单位，不复制本次实际次数与重量；模板随健康备份导出恢复，旧的单动作记录照常可用。
- 历史记录在“我的 → 全部记录”或今天页“查看全部记录”中查看、编辑和删除。
- 在“我的 → 修改目标与资料”填写身高、体重和健康目标，实时查看大号 BMI 结果、按身高换算的四档体重区间、“你”与阶段目标刻度、正常体重参考及每日热量起始建议；可切换自动建议和手动热量，保存后重开恢复。计算在本地完成，详细规则可展开查看。
- 性别、年龄均选填，可随时清空；年龄按周岁填写并自动分为未成年、成人或老年。年龄未填时注明成人参考，已知未成年或老年时保留 BMI 数值，当前不套用普通成人的分类、自动目标或默认食用量；实际食用数量仍可手填计算。
- “设置 → 外观”支持跟随系统、浅色和暗色，选择在本机保存。原始媒体、健康记录、分析版本与 Markdown 总结可导出恢复；外观偏好独立于健康备份。

未配置 AI 时仍可记录、查看本地反馈和导出。外部 AI 的费用、额度和数据保留政策由所选供应商决定。

## 检查

```powershell
npm run typecheck
npm test
npm run test:server
npm run test:scripts
```

`test:scripts` 补充诊断、实验与评估工具的专项检查，每项上限 30 秒。2026-10-23 打包前检查为 150/150 通过；历史试验仍冻结各自的 90 秒请求参数，与当前餐食每阶段 180 秒、每日总结整体 180 秒上限相互独立。修复与验证记录见 [脚本说明](scripts/README.md) 和 [维护审查](docs/maintenance-review.md)。

Web 交互及移动端、桌面端视口验证范围见[文档与验证索引](docs/README.md)；各轮结果只对对应代码快照和测试范围负责。
