# 健康记录 App UI 设计提示词

请为一个健康记录 App 设计完整的移动端界面。

## 产品定位

这是一个**本地优先**的健康数据记录工具，帮助用户追踪饮食、训练和睡眠，并通过 AI 提供营养分析和每日总结。

**核心价值**：
- 拍照记录饮食，AI 自动估算营养（热量、蛋白质、碳水、脂肪）
- 记录力量训练和有氧运动
- 记录睡眠时长和质量
- 每日生成 AI 健康总结
- 所有数据存储在本地，可导出备份

**目标用户**：
- 健身爱好者
- 需要体重管理的人群
- 关注饮食营养的人群
- 希望养成健康习惯的人群

## 功能页面

App 有 4 个主要页面（底部导航切换）：

### 1. 今天页（Today）
**核心目的**：一眼看到今日健康数据全貌

**必须展示的信息**：
- 当前日期、星期
- AI 总结状态：
  - 显示摘要来源（本地估算 / AI 生成）
  - 显示是否需要更新（有新记录但未重新分析）
  - 有触发 AI 重新分析的按钮
  - 有查看完整摘要的入口（查看后显示 Markdown 格式的总结）
- 今日饮食汇总：
  - 今日已记录几餐
  - 其中几餐有营养估算、几餐信息不足
  - 总热量范围（如 1200-1500 kcal）
  - 蛋白质、碳水、脂肪范围
- 今日训练汇总：
  - 已记录几个动作
  - 或显示"未记录"
- 今日睡眠汇总：
  - 睡眠时长（如 7.5 小时）
  - 质量评分（1-5 分）
  - 或显示"未记录"
- 今日记录列表：
  - 显示今天所有已保存的记录（饮食/训练/睡眠混合列表）
  - 点击任一记录可打开编辑
- 三个新建入口：
  - "记饮食"按钮
  - "记训练"按钮
  - "记睡眠"按钮

**交互要求**：
- 新建按钮必须清晰可见、易于点击
- 记录卡片可点击打开编辑
- AI 分析按钮和查看摘要入口明确

### 2. 记录页（Records）
**核心目的**：浏览所有历史记录

**必须展示的信息**：
- 所有历史记录（饮食/训练/睡眠）
- 按日期分组（今天、昨天、具体日期）
- 每条记录显示：
  - 记录类型图标（饮食/训练/睡眠）
  - 记录标题（食物名称 / 动作名称 / 睡眠时长）
  - 详细信息（时间、营养数据 / 组数 / 质量评分）
  - 如果是饮食且有照片，显示缩略图
- 筛选器：
  - 全部
  - 只看饮食
  - 只看训练
  - 只看睡眠

**交互要求**：
- 点击记录可打开编辑
- 筛选器切换流畅
- 长列表滚动性能良好

### 3. 趋势页（Trends）
**核心目的**：可视化健康数据趋势

**必须展示的信息**：
- 时间范围切换：近 7 日 / 近 30 日
- 三个趋势图表：
  1. **饮食频次**：每天记录了几餐（折线图或柱状图）
  2. **训练频次**：每天记录了几次训练（折线图或柱状图）
  3. **睡眠时长**：每天睡眠时长（折线图或柱状图）
- 对于没有记录的日期，保留空白（不当成零）
- 可选：显示平均值、最大值、最小值等统计数据

**交互要求**：
- 图表清晰易读
- 切换 7 日 / 30 日响应迅速
- 可以点击某一天查看该天详情（可选）

### 4. 我的页（Me / Settings）
**核心目的**：用户资料、设置和数据管理

**必须展示的功能**：
- **用户资料**：
  - 健康目标（保持健康 / 减脂 / 增肌）
  - 身高（cm）
  - 体重（kg）
  - 每日热量目标（kcal）
  - 点击可编辑
- **AI 服务设置**：
  - API 地址
  - API Key
  - 模型选择
  - 推理强度选择
  - 点击可配置
- **数据管理**：
  - 导出数据（生成 ZIP 备份）
  - 导入数据（从 ZIP 恢复）
  - 清除本机数据（需要二次确认）

**交互要求**：
- 设置项清晰分组
- 编辑表单简洁易用
- 危险操作（清除数据）有明确警告

## 表单（Modal 弹窗）

用户点击新建按钮或编辑记录时，会打开对应的表单：

### 饮食表单
**输入项**：
- 餐次选择（早餐/午餐/晚餐/加餐）
- 发生时间（日期 + 时间）
- 食物名称
- 分量描述
- 备注（可选）
- 照片（可选）
- 剩余食物描述（可选）
- 餐后照片（可选）

**特殊功能**：
- 如果有照片，有"AI 分析"按钮
- 点击后显示 AI 分析结果（食物识别、营养估算）
- 可以查看分析历史版本
- 可以手动校正 AI 分析结果

### 训练表单
**输入项**：
- 动作名称
- 发生时间（日期 + 时间）
- 训练模式（力量训练 / 有氧运动）
- 如果是力量训练：
  - 多组记录（每组：次数、重量、单位 kg/lb、是否热身组）
  - 疼痛感（是/否/未知）
  - 动作控制（是/否/未知）
  - 储备次数 RIR（0/1/2/3/4+/未知）
- 如果是有氧运动：
  - 时长（分钟）
- 备注（可选）
- 视频（可选）

### 睡眠表单
**输入项**：
- 入睡时间（日期 + 时间）
- 醒来时间（日期 + 时间）
- 清醒时长（分钟）
- 质量评分（1-5 分，星星选择）
- 备注（可选）

## 设计要求

### 技术约束
- 主要宽度：360px - 390px（移动端）
- 图标库：只能使用常见的图标（如 Ionicons）
- 无复杂动画（性能优先）
- 良好的对比度和可访问性

### 设计自由度
你可以自由决定：
- 浅色或深色主题
- 单色系或多色模块分类
- 数据密度（信息密集 vs 留白）
- 布局方式（卡片 / 列表 / 网格）
- 是否使用时间可视化（24 小时表盘 / 时间轴 / 日历 / 纯列表）
- 图表样式（折线图 / 柱状图 / 面积图 / 其他）
- 设计隐喻（仪表板 / 日记本 / 图表分析 / 地图 / 其他）

### 设计原则建议
- **移动优先**：拇指可触达，足够的点击目标
- **一目了然**：重要信息在首屏可见
- **轻量操作**：记录流程尽可能快
- **数据可信**：营养数据、趋势图表清晰可读
- **尊重隐私**：本地数据，用户掌控
