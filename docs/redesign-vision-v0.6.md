# 健康罗盘 UI v0.6 — 深夜仪表·精炼版（夜间版）

## 设计目标

基于用户更喜欢 v0.4 的反馈，在 v0.4「夜间仪表」的基础上**精炼优化**，而非推倒重来。

**这版作为夜间版长期使用，后续功能开发完成后再设计日间版。**

## 与 v0.4 的关系

**保留的核心**：
- 24 小时表盘（核心交互，今天页的灵魂）
- 三色模块分类（amber 饮食 / pine-green 训练 / periwinkle 睡眠）
- 深色主题（仪表板隐喻）
- 分层面板设计

**优化的细节**：
- **更深的基底**：从 `#0D1412` → `#05070C`（更接近纯黑，增强仪表感）
- **保持 v0.4 模块色**：
  - 饮食：`#E8A547`（琥珀金，不变）
  - 训练：`#4A998A`（青松绿，不变）
  - 睡眠：`#8B9FED`（紫藤，不变）
- **更清晰的对比度**：文字 `#E8EBF0` 在深色背景上易读
- **保留圆角系统**：12px 输入框 / 16px 卡片 / 999px 按钮（pill）

## 与 v0.3 / v0.5 的区别

| 维度 | v0.3 浅色 | v0.4 深色 | v0.5 日间 | **v0.6 夜间** |
|------|----------|----------|----------|------------|
| **基底** | 白色 | 深绿灰 | 暖白 | **纯黑** |
| **核心隐喻** | 时间线 | 仪表盘 | 地形图 | **仪表盘** |
| **24h 表盘** | ❌ | ✅ | ❌ | **✅** |
| **模块色** | 四色 | 三色 | 三色 | **三色（v0.4 原色）** |
| **使用场景** | 日间 | 夜间 | 日间 | **夜间（长期版）** |

surface-3: #161D2B  (L* ≈ 12%)

### 模块色（v0.4 原色）
```
meal:     #E8A547  (琥珀金)

sleep:    #8B9FED  (紫藤)

### 文字色
```
text-primary:   #E8EBF0  (高对比度)

## 布局原则

1. **表盘优先**：24 小时表盘是页面中心，占据主要视觉权重
2. **模块分层**：三张数据卡（饮食 / 训练 / 睡眠）垂直排列在表盘下方
3. **信息密度高**：卡片紧凑，间距统一（12px 内 / 16px 外）
4. **交互清晰**：新建按钮为 pill 形态，触摸面积足够

## 为什么这样设计

1. **尊重用户偏好**：用户明确表示更喜欢 v0.4，所以恢复其核心设计
2. **深化不破坏**：只在基底色上做深化（更黑），保持模块色不变
3. **夜间长期版**：这版作为夜间版长期使用，后续再设计日间版
4. **表盘是灵魂**：24 小时可视化是 v0.4 的核心价值，必须保留

## 实现细节

- **只改两个文件**：`src/ui/theme.ts` 和 `src/ui/today.tsx`
- **保留所有功能**：新建、编辑、AI 分析、查看摘要
- **通过所有测试**：82 个单元测试 + typecheck
- **响应式设计**：390px 和 360px 宽度均无溢出
