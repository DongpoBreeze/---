# 健康罗盘 UI v0.8 — 瑞士体征协议与 24 格节律矩阵

## 1. 整体设计理念（Design Philosophy）

**核心隐喻：瑞士体征协议与 24 格节律矩阵（Biometric Protocol & 24-Slot Rhythm Matrix）。**
不同于 v0.6 的「深夜机械表盘」和 v0.7 的「模拟记录仪纸带」，v0.8 以瑞士现代医疗档案与习惯节律矩阵为灵感，把每日健康管理重塑为一份**冷静、结构化、高可读性的个人生理协议单（Daily Biometric Ledger）**。

**为什么选择这个方向：**
1. **条形码式 24 格节律矩阵**：将一天量化为 24 根垂直小时柱（`00:00`–`23:00`）。有记录的小时点亮对应模块信号色（同一小时多模块自动垂直分段叠放），当前小时由碳黑顶冠与边框锁定。用户一眼即可分辨全天活跃时段与作息空白。
2. **协议级信息密度与可信感**：健身与控重人群需要立即读出热量区间、三大营养素（蛋白质/碳水/脂肪）、训练组数与睡眠质量评分，而非只看装饰图形。通过 `01 / NUTRITION`、`02 / 今日训练`、`03 / 今日睡眠` 的编号模块化布局，首屏即可掌握全貌。
3. **目标用户感受**：秩序感、客观可信、零打扰——本地数据主权清晰可见，AI 分析状态（来源、是否过期需重算）一目了然。

## 2. 视觉系统（Visual System）

### 调色板（Palette）
| 角色 | 色值 | 说明 |
|---|---|---|
| 矿石白画布（Paper） | `#F4F5F7` | 全局页面底色，降低纯白眩光 |
| 档案白卡片（Surface） | `#FFFFFF` | 模块面板、列表与输入框表面 |
| 碳黑主墨水（Carbon Ink） | `#0D1117` | 主标题、核心读数、主操作按钮、选中态 |
| 次级文字 / 弱刻度 | `#4B5563` / `#8B95A5` | 辅助说明、时间戳、未记录占位 |
| 结构分割线（Line） | `#E2E6ED` / `#C8D0DC` | 1px 瑞士网格边框与分割线 |
| `01` 饮食信号（朱砂珊瑚） | `#D94E34` | 饮食模块主色（浅底 `#FDF0ED`） |
| `02` 训练信号（翡翠绿） | `#0E9F6E` | 训练模块主色（浅底 `#ECFDF5`） |
| `03` 睡眠信号（钴蓝） | `#2563EB` | 睡眠模块主色（浅底 `#EFF6FF`） |
| 警告 / 危险操作 | `#D97706` / `#DC2626` | AI 总结待更新提示 / 删除本机数据警告 |

### 排版方案（Typography）
- **标题与正文**：系统无衬线字体。
  - `display`：30px / 行高 36 / 字重 800（页面主标题、日期）
  - `title`：19px / 行高 25 / 字重 800（区块标题）
  - `heading`：15px / 行高 21 / 字重 700（卡片标题）
  - `body`：15px / 行高 22（正文与摘要）
  - `small`：12px / 行高 18（次要说明）
- **协议编号与读数（Monospace）**：`Menlo / monospace` + `tabular-nums`。
  - `caption`：11px / 字距 1.2 / 字重 700，用于 `DAILY PROTOCOL`、`24H RHYTHM MATRIX`、`01 / NUTRITION` 等协议索引。
  - `reading`：28–30px / 字重 800，用于热量范围、记录条数、训练动作数与睡眠时长。

### 间距与圆角规范（Spacing & Radius）
- **间距梯度**：`4 / 8 / 12 / 16 / 24 / 32 / 48 px`。页面水平内边距 `20px`，卡片内边距 `12–16px`，模块间距 `12px`。
- **圆角规范**：输入框与内部小指标卡 `6px`，模块大卡片与主按钮 `10px`，胶囊状态标签与底部导航 `999px`。

## 3. 页面设计描述（Page Specifications）

### 1. 今天页（Today）
- **协议抬头**：显示 `DAILY PROTOCOL`、累计记录天数徽章、当前月日与星期，右侧为个人资料快捷按钮。
- **24 格节律矩阵（招牌可视化）**：24 根垂直小时柱映射全天三项记录，顶部 `NOW HH:mm` 实时指示，底部汇总今日总记录条数与活跃时段占比。
- **三联新建入口**：位于矩阵正下方拇指热区——碳黑实心主按钮「记饮食」+ 带模块信号点的「记训练」「记睡眠」按钮（高度 52px）。
- **三大体征汇总卡**：
  - `01 / NUTRITION`：展示已记餐数、有估算餐数与信息不足餐数、总热量范围（kcal）及**蛋白质 P / 碳水 C / 脂肪 F 范围三格矩阵**。
  - `02 / 今日训练` 与 `03 / 今日睡眠` 双栏并排：训练展示动作数与工作组/有氧时长；睡眠展示时长（小时）与 **1–5 分五格质量信号条**。
- **AI 总结状态卡**：右上角双徽章明确标注**摘要来源（AI 生成 / 本地估算）**与**更新状态（有新记录需重新分析 / 已是最新）**；提供展开完整 Markdown 摘要与「请求 AI 综合分析」按钮。
- **今日记录列表**：按发生时间倒序混合展示今日饮食、训练、睡眠记录，点击任一行直接打开编辑。

### 2. 记录页（Records）
- **筛选器栏**：置顶胶囊筛选器（全部 / 饮食 / 训练 / 睡眠），带模块色点与实时条数。
- **按日期分组列表**：以「今天」「昨天」及具体日期分组；每张记录卡左侧嵌 4px 模块色脊，展示餐食缩略图或模块图标、标题、时间与核心营养/组数/睡眠评分，右侧提供单餐 AI 分析与删除按钮。

### 3. 趋势页（Trends）
- **7 日 / 30 日分段控制器**：高对比度碳黑选中态。
- **记录覆盖矩阵（可交互）**：三模块 × N 天的条形码式覆盖网格，**点击任意一天列或柱状图柱体即可展开该日记录详情卡**。
- **三张趋势柱状图**：饮食频次、训练频次、睡眠时长；未记录日保留空槽（绝不当作 0），每张图顶部新增 **平均值（AVG）/ 最高值（MAX）/ 最低值（MIN）** 统计条。

### 4. 我的页（Me / Settings）
- **用户资料协议卡**：展示当前目标（保持健康 / 减脂 / 增肌）与身高、体重、每日热量目标三格读数，点击打开编辑。
- **AI 服务设置与本地数据管理**：分组展示 AI 模型配置、导出完整 ZIP 备份、导出今日 Markdown、恢复备份及红色警告的「删除本机数据」。

## 4. 关键交互说明（Key Interactions）

1. **新建记录流程**：在今天页点击「记饮食 / 记训练 / 记睡眠」→ 滑出顶部带对应模块色边的 `pageSheet` 弹窗 → 录入时自动保存本地草稿 → 点击右上角「保存」后立即更新 24 格节律矩阵与汇总卡片。
2. **编辑记录流程**：在今天页或记录页点击任意已保存记录 → 打开预填原数据的同款表单 → 修改并保存后，关联的当日摘要自动标记为需更新，且历史 AI 分析版本完整保留。
3. **AI 分析触发与结果查看**：
   - **饮食照片识别**：在饮食表单上传照片后自动或手动触发 AI 识别，返回每 100g 营养参考区间，用户填写食用量后即时算出本餐热量与三大营养素范围，并支持手动校正与历史版本回看。
   - **每日 AI 总结**：在今天页点击「请求 AI 综合分析」，经用户确认后发送当日快照，生成独立版本的 Markdown 总结。
4. **数据导出流程**：进入「我的 → 导出完整备份」，在本地将全部 JSON 记录、照片/视频媒体与每日摘要打包为 ZIP 文件并调用系统分享或浏览器下载。
