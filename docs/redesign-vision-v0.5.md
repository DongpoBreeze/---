# 健康罗盘 v0.5 视觉方向：「日间地图」

## 设计意图

v0.5 建立一个明亮、温暖、有机的视觉系统，用**地形高度**隐喻数据层级：最深的信息是"地面"，最重要的数据浮起成"山峰"。抛弃时间轴和表盘，改用**数据卡片的垂直分层**呈现今天页。

## 与 v0.3 / v0.4 的区别

| 维度 | v0.3 浅色时间线 | v0.4 夜间仪表 | v0.5 日间地图 |
|-----|----------------|--------------|--------------|
| **基底** | 浅灰 `#F8FAF9` | 深绿灰 `#0D1412` | 暖白 `#FBF9F6` |
| **隐喻** | 时间线（线性流动） | 仪表盘（24 小时表盘） | 地形（数据分层） |
| **主色** | Pine `#2D7A6C` | Pine `#7ED6B8` | 青铜绿 `#5A8A6F` |
| **模块色** | Amber / Red / Indigo | Amber / Ember / Periwinkle | Terracotta / Bronze-green / Amber-gold |
| **核心组件** | 时间线 + 记录卡片 | 24 小时表盘 + 三色指示灯 | 三张数据卡 + 操作按钮 |
| **阴影** | 有（卡片投影） | 无 | 无 |
| **圆角** | 12px | 18px（block）、999px（pill） | 16px（block）、999px（pill） |

**核心差异**：
- v0.3 的时间线是**横向流动**，强调记录的时间顺序
- v0.4 的表盘是**径向结构**，24 小时围成一圈，强调一天的循环
- v0.5 的地图是**垂直分层**，数据卡片堆叠，强调信息的重要性层级

## 调色板

### 基底（五级浮雕面）
- `paper`: `#FBF9F6` —— 最底层，象牙白
- `surface`: `#F5F2ED` —— 卡片默认层
- `raised`: `#EAE5DD` —— 提升层（今日摘要面板）
- `sunken`: `#F0EBE3` —— 下沉层（输入框）
- `line`: `#E0DAD0` / `lineStrong`: `#D0C8BA` —— 分隔线

### 文字
- `ink`: `#2A2420` —— 主文字（深褐）
- `inkSoft`: `#6B6258` —— 次要文字
- `inkFaint`: `#9D9488` —— 辅助文字

### 强调色（从领域取色）
- `accent`: `#5A8A6F` —— 青铜绿（链接、AI 按钮）
- `accentTint`: `#EBF3EE` —— 青铜绿淡色（按钮背景）

### 模块色
- **饮食**：`meal`: `#C8593E`（赤土橙）、`mealText`: `#A8422A`、`mealTint`: `#F9EBE7`
- **训练**：`training`: `#5A8A6F`（青铜绿）、`trainingText`: `#3D6B51`、`trainingTint`: `#E8F0EC`

**色相逻辑**：
- 赤土橙取自陶器、食物的自然色
- 青铜绿取自金属、力量的稳定色
- 琥珀金取自夜灯、温暖的休憩色

## 排版

所有字阶采用固定像素（React Native 不支持 `clamp()`），但保留足够的层级对比：

- `display`: 32px / 38px 行高 / -0.6 字距 / 800 粗细
- `title`: 22px / 28px / 700
- `heading`: 17px / 24px / 700
- `body`: 15px / 24px（1.6 倍行高，适合阅读）
- `bodySoft`: 15px / 24px / 柔和色
- `small`: 13px / 19px
- `label`: 14px / 20px / 600
- `reading`: 36px / 40px / 800（大号数值显示）

**排版原则**：
- Display 用负字距（-0.6）收紧视觉
- Body 行高 1.6，确保段落舒适阅读
- 数值类文字（卡路里、时长）使用 `fontVariant: ["tabular-nums"]` 保持等宽对齐

## 布局原则

### 今天页结构
1. **顶部栏**：日期（星期 + 月日）+ 用户头像
2. **统计行**："已有 N 个日期留下记录"
3. **数据卡片区**：三张横向卡片（饮食 / 训练 / 睡眠），每张显示：
   - 图标 + 标签
   - 核心数值（大号）+ 单位
   - 副标签（状态描述）
4. **操作按钮区**：三个按钮（记饮食占 1.5 份宽度，记训练、记睡眠各占 1 份）
5. **提示文字**："拍照或直接写下吃了什么"
6. **今日摘要面板**：
   - 面板标题 + "根据已保存记录"
   - 摘要预览文本
   - "查看完整摘要"链接
   - AI 历史版本列表（如有）
   - "请求 AI 综合分析"按钮
7. **今日记录列表**：
   - 标题："今日记录"
   - 记录列表（每条一行，左侧色点 + 标题 + 详情 + 右箭头）
   - 或空状态："暂无记录"

### 设计 token
- **间距**：`xs: 4, sm: 8, md: 12, lg: 16, xl: 24, xxl: 32, xxxl: 48`
- **圆角**：`input: 12, block: 16, pill: 999`
- **模块标识**：每个模块有专属色（hue）、文字色（text）、淡色背景（tint）、图标

### 层级策略
- 不用阴影，依靠背景色阶区分层次
- 数据卡片：`borderWidth: 1.5`，有数据时用模块色边框，无数据时用 `line` 边框
- 按钮：primary 用模块色填充，secondary 用模块色描边 + 透明底
- 面板：用 `raised` 背景色（比 `paper` 深一级），与卡片区分

## 今天页特定决策

### 为什么去掉 24 小时表盘？
- v0.4 的表盘在视觉上是亮点，但**信息密度低**：用户第一眼想看的是"今天吃了多少热量"、"训练了几次"，而不是"几点吃的饭"
- 表盘占据大量垂直空间（240-300px），在小屏手机上挤压了数据和列表的显示
- 时间信息已经在记录列表的"详情"中展示（如"午餐 · 12:30"），不需要单独可视化

### 为什么用三张数据卡而不是三行 Gauge？
- v0.4 的 Gauge 是垂直窄条，三个并排时每个宽度约 110px，数值 + 单位 + 副文字挤在一起，`adjustsFontSizeToFit` 频繁触发
- v0.5 的数据卡有足够的内部空间：图标 + 标签在顶部，数值大号居中，副文字在底部，层级清晰
- 卡片背景色用模块淡色填充（有数据时），视觉上更"浮起"

### 为什么把"记饮食"按钮放更大？
- 饮食是三个模块中**使用频率最高**的（每天至少 3 餐，训练和睡眠通常各 1 次）
- 饮食有拍照入口，图标用 `camera`，需要更大的点击区域
- `flex: 1.5`（记饮食）vs `flex: 1`（记训练、记睡眠）的比例，在 390px 宽度下是 ~195px vs ~130px，足够区分主次

### 为什么今日记录列表不再用"时间轨"（rail）？
- v0.4 的时间轨（左侧色点 + 竖线）占据 14px 宽度，在 360px 屏幕上略显浪费
- v0.5 只保留色点（10px），去掉竖线，记录之间用 1px 分隔线（`borderBottomColor: color.line`）
- 列表最多显示 8 条（`slice(0, 8)`），超过 8 条需要去"记录"页查看

## 后续建议

**里程碑 2**（记录页与趋势页）可以继续沿用这套调色板和 token，将地形隐喻延伸到列表和图表：
- 记录页：按日期分组的卡片，每个日期是一个"地层"
- 趋势页：折线图用模块色，背景用 `raised` 面

**里程碑 3**（表单优化）需要重点处理输入框和 Picker 的视觉：
- 输入框用 `sunken` 背景（下沉，强调"待填写"）
- 已填写的值用 `ink` 颜色
- Placeholder 用 `inkFaint`

**里程碑 4**（我的页）可以用青铜绿（`accent`）作为"设置"和"导出"的强调色。

**里程碑 5**（动效）建议加入：
- 数据卡片的微弹跳动画（数据更新时）
- 按钮按下的缩放反馈（`scale: 0.96`）
- 记录列表的进入动画（`opacity` + `translateY`）
