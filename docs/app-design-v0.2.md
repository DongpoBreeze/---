# 健康罗盘页面重设计 v0.2

日期：2026-10-12。目标：通过 Figwright 在连接的 Figma 文件中交付可编辑页面、共用组件和核心流程原型。以当前 App 行为为依据，设计稿不表示原生功能、供应商兼容性或营养准确率已验收。

## 范围与设计约定

- 四个主页面：今天、记录、趋势、我的；饮食拍照为今天页面的主要入口。
- 饮食：新增/编辑、照片与分析授权、分析结果、食材校正、分析版本历史。
- 训练：力量/其他运动记录、工作组与热身组、进阶反馈、视频附件。
- 睡眠：入睡/起床时间、清醒时长的未知与明确为零、主观质量和时长反馈。
- 每日摘要、个人资料与目标、用户自选 AI 服务、模型选择、数据导出/恢复/删除。
- 补充首次无数据、AI 等待、失败与信息不足状态；不在设计中承诺不存在的通知、设备接入或云同步。
- 健康数据与 API 凭据分开管理；API 示例使用 example.com 与遮罩字符串，设计稿只含虚构记录及公开演示照片。

营养详情明确计入来源，手动值优先，未知值保持为空；睡眠区分入睡至起床区间与扣除清醒时长后的估算；RIR 表示整次训练的最少剩余次数，只在训练反馈和详情中显示一次。模型与档位只依据所选服务返回的信息展示。备份恢复合并记录，重复记录跳过，冲突时中止。

视觉保留代码中的品牌绿 `#16745E` 与训练珊瑚色 `#C96555`；引入中性灰和睡眠蓝。间距使用 4/8/12/16/24/32/48 的刻度，主要字号使用 12/14/16/20/24/32，卡片圆角不超过 8。主要手机视口为 390 x 844，并检查 360 宽度适配。页面分区采用未加框的布局；卡片只用于重复记录和有明确边界的工具。输入、选项与图标采用对应的常见控件。

## 验收

1. 页面与源代码当前流程对应，三模块均可独立进入；不强迫先填写资料或 AI 配置才能记录。
2. 组件使用 Auto Layout、可复用实例、共享颜色/文字样式和真实字体、图标资源。当前 Figwright 会话未能创建变量集合，因此间距和颜色没有声明为 Figma Variables。
3. 饮食未知值不显示为零，不把数据库示例计算当作照片的真实热量；校正与旧分析能够区分。
4. 关键按钮、底部导航和返回路径连接为 Figma 原型；取消/失败路径能回到保留输入的记录页。
5. 导出截图并逐页检查遮挡、溢出、字号与信息层级；交付页面目录、节点 ID 和本地预览。
