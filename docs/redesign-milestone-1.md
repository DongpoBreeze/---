# 前端重设计里程碑 1：主视图与数据可视化

**目标**：建立新的视觉系统，重做今天页的数据呈现，确保现有功能不变。

## 背景

当前 v0.4 是"夜间仪表"深色方案，今天页中心是 24 小时表盘。本次重设计需要一个全新的视觉方向，与 v0.3（浅色）、v0.4（深色表盘）明显不同。

## 里程碑 1 范围

**做什么**
1. 确定新视觉方向（调色板、排版、布局原则）
2. 重做今天页（Today）的数据呈现与布局
3. 确保所有现有数据都正确展示，不丢失功能

**不做什么**
- 不改记录页（Records）、趋势页（Trends）、我的页（Me）
- 不改任何表单（饮食、训练、睡眠、资料、AI 设置）
- 不改数据结构、存储、AI 调用逻辑
- 不改测试用例

## 验收标准

**视觉**
- 提出一个明显区别于 v0.3/v0.4 的视觉方向，包括：
  - 调色板（主色、模块色、状态色）
  - 排版方案（字体、字阶、行高）
  - 布局原则（卡片 vs 列表 vs 其他）
- 今天页能展示：
  - 当前日期、星期
  - AI 总结状态（本地/AI，是否待更新，可触发分析）
  - 今日饮食摄入汇总（已估算 / 未估算餐数，热量、蛋白质、碳水、脂肪范围）
  - 今日训练汇总（已记录动作，或"未记录"）
  - 今日睡眠汇总（时长、质量，或"未记录"）
  - 三个新建入口按钮（饮食、训练、睡眠）
  - 今日已保存记录列表（点击可打开编辑）

**功能**
- 今天页所有交互完整：新建、编辑、触发 AI、查看摘要
- 其余三页（记录、趋势、我的）保持原样可用
- 底部导航正常切换
- 60 个单元测试全部通过
- typecheck 无错误
- 至少 14/16 个浏览器流程测试通过（AI 设置预填问题已知）

**代码**
- 只改 `src/ui/today.tsx` 和 `src/ui/theme.ts`
- 可新增组件文件到 `src/ui/`
- 不改 `src/types.ts`、`src/storage.ts`、`src/domain.ts`、`src/ai.ts`
- 不改 `App.tsx` 除了 import 路径之外的任何内容
- v0.4 的今天页备份到 `artifacts/backup/ui-v0.4/today.tsx.bak`

**交付物**
- `src/ui/theme.ts`（新调色板）
- `src/ui/today.tsx`（新今天页）
- `docs/redesign-vision-v0.5.md`（视觉方向说明：为什么这样设计，与 v0.3/v0.4 的区别）
- `artifacts/ui-v0.5/today-390.png`（390px 宽度截图）
- `artifacts/ui-v0.5/today-360.png`（360px 宽度截图）

## 设计约束

**必须保留的信息**
- 今日所有记录的完整可见性（不能隐藏或折叠必要信息）
- AI 总结的来源、状态、更新时间
- 每餐的估算状态（已估算 / 待估算 / 信息不足）
- 训练的组数、重量、次数
- 睡眠的时长、质量分数、清醒时长

**交互不能退化**
- 点击记录卡片必须能打开编辑表单
- 点击"记饮食"等按钮必须能打开新建表单
- 触发 AI 分析的按钮清晰可见
- 查看摘要的入口明确
