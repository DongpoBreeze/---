# 健康罗盘 UI v0.7 — 多通道记录仪（日间版）

## 1. 整体设计理念

**核心隐喻：多通道图表记录仪（strip-chart recorder）。** 实验室和气象站里，记录仪用几支彩色笔在坐标纸带上同时描出多路信号——每一路互不干扰，又共享同一条时间轴。健康罗盘记录的正是三路信号：饮食、训练、睡眠。

**为什么换掉表盘：** v0.4/v0.6 的 24 小时表盘很有仪式感，但环形把"时间"折叠成角度，三类记录挤在同一个圆周上互相覆盖，读不出"几点吃饭、几点训练"的先后关系。纸带把一天展开成一条水平轴，三个通道各占一行：睡眠是一段实线，饮食和力量训练是带笔点的刻度，有氧是一段笔画。用户从左到右扫一眼，就能看到一天的节奏。

**为什么是浅色坐标纸：** 记录工具的本质是"可信的数据"。浅灰绿坐标纸 + 藏青记录墨水，像一份可以签字归档的实验记录；三支笔色（记录红 / 野外绿 / 图表蓝）直接取自真实记录仪的笔色，饱和度高、在浅底上对比度达 AA。数字统一使用等宽字体，读数像仪器输出一样整齐。

**用户感受：** 冷静、精确、可信——"我的数据被认真地记录着"，而不是被游戏化或被评判。

## 2. 视觉系统

### 调色板（5 色）
| 角色 | 色值 | 用途 |
|---|---|---|
| 坐标纸（背景） | `#F2F4F1` | 页面底色 |
| 纸面 / 卡片 | `#FBFCFA` | 面板、输入框 |
| 记录墨水（主色） | `#17202B` | 文字、主按钮、选中态、NOW 指针 |
| 饮食笔 | `#C8372D` | 饮食通道、记饮食主按钮 |
| 训练笔 | `#1E7A4F` | 训练通道 |
| 睡眠笔 | `#2D4FB3` | 睡眠通道 |

辅助：网格线 `#E3E8E2`（每小时）/ `#B9C3BB`（每 6 小时）；每支笔都有 tint（浅底）和 line（描边）两个派生色，仅作为同色系浅化使用。

### 排版
- 标题/正文：系统无衬线（PingFang / Roboto）。display 30/36 800，title 20/26 700，heading 16/22 700，body 15/23。
- 读数/刻度：等宽字体（Menlo / monospace），`tabular-nums`。caption 11/14 700，字距 1，用于 "24H 记录纸带"、"NOW 08:42" 等仪器标签。

### 间距
4 / 8 / 12 / 16 / 24 / 32 / 48。页面左右 20，卡片内边距 12–16，卡片间距 12。

### 圆角
输入框 8，卡片 10（比 v0.6 更硬朗，接近纸张裁切），按钮 pill 999。

## 3. 页面设计

### 今天页
1. 头部：星期（等宽 caption）+ 日期（display），右侧资料入口。
2. **24H 记录纸带**（招牌元素）：三通道 × 24 小时网格，NOW 指针为一根墨水竖线；底部显示"N 条今天已记下"。
3. 三个读数卡：已估算摄入（kcal 范围）/ 训练次数 / 估算睡眠，顶部 3px 笔色线；未知时笔色线变灰。
4. 新建入口：「记饮食」红色实心主按钮 + 「记训练」「记睡眠」描边按钮，全部 ≥56px 高。
5. 今日摘要面板：来源说明、展开完整 Markdown、AI 版本历史、"请求 AI 综合分析"按钮。
6. 今日记录：带笔色圆点的时间轴列表，点击进入编辑。

### 记录页
标题 + 横向筛选器（全部/饮食/训练/睡眠，带计数和笔色点）置顶；按日期分组（今天/昨天/具体日期），每条记录：笔色图标、标题、等宽细节行，饮食有照片显示缩略图。

### 趋势页
7/30 日分段切换（墨水色选中）→ 记录覆盖网格（三通道 × N 天，像纸带的缩略版）→ 三张柱状图。未记录日保留空槽，绝不画成 0。

### 我的页
资料卡（目标、身高、体重、热量目标）→ AI 服务设置 → 数据管理（导出 ZIP / 导入 / Markdown / 清除），危险操作使用 `#B42318` 并二次确认。

## 4. 关键交互
- **新建记录：** 今天页三按钮 → 底部 pageSheet 表单 → 保存后纸带对应通道立即出现新笔迹。
- **编辑记录：** 今天页或记录页点击任一条 → 同一表单预填 → 保存/删除。
- **AI 分析：** 饮食表单有照片时出现"AI 分析"；结果与原始输入分开保存、可查看历史版本与手动校正。今天页"请求 AI 综合分析"发送前询问同意。
- **数据导出：** 我的 → 数据管理 → 导出数据，生成 ZIP 并调用系统分享。
